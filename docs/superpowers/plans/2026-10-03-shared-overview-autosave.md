# Shared Overview and Autosave Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cho mọi nhân viên xem đơn/bill chung realtime, với tự lưu hoặc submit theo tài khoản.

**Architecture:** Mở SELECT đơn cho thành viên active, bổ sung projection bill/roster/actor giới hạn và cấu hình bill theo ngày. Database là nguồn tính bill/chia tiền cho cả preview và quyết toán; controller autosave tuần tự xử lý version/idempotency/xung đột, tách khỏi global busy của App. Reuse refresh batching 300ms.

**Tech Stack:** React/TypeScript, Supabase Postgres/RLS/Realtime, Cloudflare Workers, Vitest/PGlite, Playwright; không thêm dependencies.

**Spec:** `docs/superpowers/specs/2026-10-03-shared-order-overview-design.md`

## Global Constraints

- Autosave mặc định, debounce 700ms; preference lưu theo tài khoản, dùng người thao tác khi đặt hộ.
- Giờ chốt 17h hôm trước không khoá đơn; khoá thủ công/kỳ quyết toán giữ nguyên.
- Shared order/bill access không mở ledger, payments, email hoặc audit người khác.
- Mỗi lần ghi thành công giữ audit/Chat/idempotency; không gửi Chat thử phòng thật.
- Preserve Cloudflare secrets, bindings và `global_fetch_strictly_public`; dùng typed asset uploader và kiểm tra live MIME.
- Không merge main; triển khai staging sau kiểm thử/review và lưu source vào feat/webapp-v1.

## Review Focus

1. Người khác đổi đơn trong lúc đang tự lưu: không mất bản nháp, không tự ghi đè; test Task 4.
2. Request thành công nhưng response mất: retry cùng request ID, không ghi trùng; test Tasks 1/4.
3. Người tài trợ huỷ đơn hoặc trọng số tiền món bằng 0: báo bill cần kiểm tra, chặn quyết toán; test Task 2.
4. Đổi ngày/người/logout khi có pending: không gửi nhầm chủ thể/mất nháp âm thầm; test Task 5.
5. Client cũ gửi tổng quyết toán hoặc profile không có preference: không bỏ qua bill mới/đổi preference ngoài ý muốn; test Tasks 1/2.

## File boundaries and shared interfaces

- `shared/contracts.ts`: Member.order_save_mode: `autosave | manual`; BillConfig/BillPreview/OrderActor types, optional snapshot.shared; tương thích fixture cũ bằng fallback.
- `public.daily_bills`: day_id PK, discount_kind (none/fixed/percent), discount_value numeric, fee bigint, covered/sponsors JSON arrays, version integer, updated_at. SELECT cho thành viên active; không cấp direct write.
- `private.bill_preview(day_id uuid) returns jsonb`: `{dayId, state, original, discount, fee, total, shares:[{memberId, amount}], warnings, version}`. Dùng private.allocate và tham số bill hiện tại hoặc snapshot quyết toán.
- `private.shared_overview() returns jsonb`: `{roster:[{id,display_name,active}], bills:BillPreview[], actors:OrderActor[]}`; actor gồm orderId, actorId/name, updatedAt, kind; không before/after/email.
- `public.snapshot()` giữ security invoker, thêm shared projection; các helper private auth-gated và execute tối thiểu.
- `src/lib/api.ts`: `ApiError extends Error {code:string; status:number}`; `command(kind,payload,version=0,requestId=crypto.randomUUID())` giữ default tương thích.
- `src/lib/order-autosave.ts`: controller độc lập React, giao tiếp `{submit:(request:OrderRequest)=>Promise<Order>, onChange:(state:AutosaveState)=>void}`; `OrderRequest={kind,payload,version,requestId}`; methods edit, acknowledge, retry, discard, dispose; không đổi chủ thể bên trong controller.
- `src/features/useOrderDraft.ts`: React adapter, quản lý controller cho `{dayId,memberId}` và guard chuyển chủ thể; `commitOrder` của App trả Order từ response trước khi refresh, không chờ snapshot để lấy version.
